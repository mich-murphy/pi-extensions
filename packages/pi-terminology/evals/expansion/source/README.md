# Historical 51-concept expansion sources

These inert `.txt` snapshots preserve all 18 sources bound by the original
[frozen expansion](../frozen-cutoffs.json). They were recovered byte-for-byte from
the subsequent recall run's preserved source archive, and every hash was checked
against the original freeze before copying.

The [manifest](../source-manifest.json.txt) records their original paths. Historical
expansion replay tests use these archived glossary/policy/source bytes, not later
recognizer or manual-preview changes. Original receipts, observations, thresholds,
reports, approval boundaries and consumed budgets remain unchanged.

These files are evidence only: no historical result approves a new catalogue,
experimental preview, activation or paid replay.
