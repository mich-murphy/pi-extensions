# Frozen ten-concept source snapshots

These are byte-for-byte copies of the eleven source files committed by the
[production manifest](../manifest.json). The `.txt` suffix makes them inert
provenance records, not a second extension or executable evaluation path.

Their SHA-256 hashes match the original manifest. The original datasets,
observations, aggregate report, manifest and consumed private receipts have not
been rewritten. Offline evidence tests validate these snapshots and the archived
[core glossary](../core.json) and [policy](../policy.json), rather than falsely
binding the historical ten-concept result to the expanded runtime catalogue.

Do not format or edit snapshot bytes. New runtime verification belongs in a new
experiment with fresh data and a separate durable budget ledger.
